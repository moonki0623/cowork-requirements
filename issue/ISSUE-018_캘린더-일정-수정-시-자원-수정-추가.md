# ISSUE-018: 캘린더 일정 수정 시 자원 수정 추가
> **제품**: Mattermost Calendar 플러그인
> **유형**: `신규` / `UI 변경`
> **작성자**: 권현준 매니저
> **작성일**: 2026-07-02
> **상태**: `Open`
> **관련 PRD**: [PRD-001](../PRD/PRD-001_마이스퀘어-회의실-예약-연계.md)

---

## 1. 현상 / 요청 내용

- 일정 시간이 수정될 경우, 자원예약도 같이 수정하시겠습니까? 체크박스를 등장시킨다.
- 체크 시, 일정에 저장된 예약번호로 예약현황에서 기존 예약을 찾아 세팅한 뒤 수정한다
---

## 2. 기대 결과 (To-Be)

- 시간 변경 감지 시 DateID/BookingID가 Null이 아닐 경우 체크박스 노출.
- 체크 시: 저장된 booking_id(BookingID) / date_id(DateID) 로 예약현황에서 기존 예약을 매칭·세팅.
- 이후 흐름은 등록과 동일: [자원 예약하기] → 빨간 줄 결과 → [일정 등록하기] → 실패 시 "일정만 단독 등록?" 알림.
- 체크하지 않으면 일정만 수정(예약 변경 없음).

---

## 3. 재현 경로 (버그일 경우)

- 해당 없음 (기능 추가)

---

## 4. 대상 화면 / 영향 범위

- 모바일 / 데스크탑 대상 화면: 일정 수정 팝업
- 영향 범위: 예약이 연결된 일정을 수정하는 사용자

---

## 5. Before / After (UI 변경일 경우)

**Before**
> 회의실 예약이 마이스퀘어를 통해서 진행해야함

**After**
> 시간 변경 시 '자원예약도 같이 수정' 체크 → 예약번호로 기존 예약 세팅 후 수정

---

## 6. 구현 메모

- 트리거: 일정 시작/종료 시간 변경 감지.
- 매칭: outlook_calendar의 booking_id/date_id로 예약현황 조회에서 필터링
- 버튼/결과/실패 알림은 ISSUE-017과 동일 로직 재사용.

- 인라인 펼침은 단일 팝업(별도 팝업/모달 아님, 스크롤로 연결).
- 관심회의실 트리 컴포넌트는 회의실 함께보기 팝업(ISSUE-015)과 UI 공유.
- 시간표 시간대 클릭 → 예약 폼으로 시간/장소 매핑 + 포커스.

- 자원 목록 API -> [ISSUE-015 참조](issue/ISSUE-015_캘린더-회의실-함께보기-팝업-추가)
- 예약 현황 API -> [ISSUE-016 참조](issue/ISSUE-016_캘린더-회의실-함께보기-일정표출)
- 예약 등록 API -> [ISSUE-017 참조](issue/ISSUE-017_캘린더-일정-등록-시-자원-예약-추가)
- 예약 수정 API -> [ISSUE-017 참조](issue/ISSUE-017_캘린더-일정-등록-시-자원-예약-추가)
