## 1. 현상 / 요청 내용
 
- 일정 상세보기에서는  **일정 장소(location)만** 표출한다. -> 현상황 유지
- 회의실(자원) 장소·예약 상세 등은 표출하지 않는다.
- 자원 예약 상세보기에서는 자원 예약 현황 API에서의 정보만 표출하면 된다.
---
 
## 2. 기대 결과 (To-Be)
 
- 자원예약/일정은 별개의 자원으로써 각각의 상세 정보를 조회할 수 있다.
---
 
## 3. 재현 경로 (버그일 경우)
 
- 해당 없음 (기능 추가/정책)
---
 
## 4. 대상 화면 / 영향 범위
 
- 모바일 / 데스크탑 대상 화면: 일정 상세보기
- 영향 범위: 일정 상세를 조회하는 사용자 전체
---
 
## 5. Before / After (UI 변경일 경우)
 
**Before**
> 신규 기능이라 Before 없음
 
**After**
> 일정 상세에는 일정 장소만 표출(회의실/자원 장소·예약 상세 미표출)
> 자원 상세에서는 자원 관련 정보만 표출
 
---
 
## 6. 구현 메모
 
- 일정 상세 표시 필드: 제목·시간·참석자·주최자·**장소(=일정 location)**.
- 자원 상세 표시 필드 : 예약자 / 용도 / 예약기간 / 자원명 / 자원분류 / 소속부서 (상황에 따라 표출이 어려운 것은 제거 가능, 논의 바람)

- 자원 상세 API
  - 요청 BODY JSON 항목
    - ResourceID : 자원 ID
  - 응답 JSON (필요한 값의 의미는 IT지원팀 확인 필요 ✔️)
    - FD_ID
    - DN_ID
    - DN_Code
    - ExCompanyName
    - MN_ID
    - FolderType
    - LinkFD
    - LinkFDName
    - DisplayName
    - MemberOf
    - IsUse
    - IsInherited
    - IsShared
