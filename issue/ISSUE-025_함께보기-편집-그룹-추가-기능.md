## 1. 현상 / 요청 내용
 
상황에 맞게 **이름 있는 커스텀 그룹**(예: 내 팀 / 내 동기들 / TF팀 )을 미리 만들어 두고 꺼내 쓸 수 있어야 한다. 
현행은 사람을 한 명씩 추가하는 단일 평면 리스트라, 반복 구성이 번거롭고 그룹 개념이 없다.
 
---
 
## 2. 기대 결과 (To-Be)
 
**그룹 모델**
- **그룹 = 이름 + 멤버 집합**(사용자가 **직접 검색·선택**해 편성하는 커스텀). 
- 생성 / 편집(이름·멤버) / 삭제 지원. 
- 멤버 선택은 함께보기의 검색·연속 다중 선택 UX 재사용.

**구성 플로우 (모바일 · 팝업 중첩 없음)**
1. 캘린더 `함께보기` 한 줄의 `＋` → **함께보기 편집** 시트(그룹 on/off + `새 그룹 만들기`).
2. `새 그룹 만들기` → **같은 시트가 ‘그룹 만들기’ 화면으로 전환**
3. `저장` → **함께보기 편집으로 복귀**, 새 그룹이 목록에 추가되고 OFF.
4. `완료` → 캘린더 반영.


**제약 연계**
- 1개 그룹 **최대 20명** (참고, 함께보기 총 인원도 20명 제한)

## 4. 대상 화면 / 영향 범위
 
- **함께보기 편집** 시트 — 그룹 목록 · `새 그룹 만들기` 진입 
- **그룹 만들기** 화면(같은 시트 내 전환) — 이름 · 멤버 검색·체크 · 저장
- 그룹 데이터 저장소 -> 프론트에 저장

---
 
## 5. Before / After
 
**Before** — 단일 평면 리스트(단일 그룹). 사람을 매번 한 명씩 추가.
 
**After**
```
편집 시트:  내 팀 / 내 동기들 / 임원분들 (이름 그룹)  + [새 그룹 만들기]
새 그룹:    ← 그룹 만들기 | 이름[기획 TF] | 멤버 검색·체크 | [저장]
저장 → 편집 복귀(기획 TF 추가·ON) → 완료 → 캘린더 반영
```
